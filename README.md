Repositori ini dibuat untuk mendokumentasikan seluruh rangkaian tugas praktikum mata kuliah Pemrograman Web, mulai dari pengenalan dasar web hingga implementasi interaktivitas menggunakan JavaScript DOM dan *Event Handling*.

---

## 🎯 Tujuan Pembelajaran Keseluruhan
* Memahami struktur dasar pembuatan dokumen web HTML5 yang semantik.
* Menguasai teknik perancangan antarmuka responsif menggunakan CSS modern.
* Menerapkan logika pemrograman JavaScript untuk memanipulasi elemen DOM secara dinamis.
* Menangani berbagai *event* pengguna (`click`, `input`, `submit`, `reset`) dengan *event listener*.
* Membangun sistem validasi sisi klien (*client-side form validation*) serta fitur interaktif.

---

Cara Menjalankan Proyek
1.⁠ ⁠Pastikan aplikasi Visual Studio Code terpasang di perangkat Anda.
2.⁠ ⁠Pasang ekstensi Live Server di dalam VS Code.
3.⁠ ⁠Clone atau buka direktori repositori ⁠Lab6Web⁠ ini melalui VS Code.
4.⁠ ⁠Buka folder latihan atau sub-proyek yang ingin diuji (misalnya folder ⁠lab6_dom_event⁠).
5.⁠ ⁠Klik kanan pada file ⁠index.html⁠, lalu pilih "Open with Live Server".

Langkah Kerja & Ringkasan Pengerjaan
 Penyusunan Struktur & Layout: Membangun kerangka HTML dari dasar hingga tata letak kompleks menggunakan Flexbox/Grid.
 Implementasi JavaScript DOM: Menggunakan method seperti ⁠getElementById⁠, ⁠querySelector⁠, dan ⁠querySelectorAll⁠ untuk menyeleksi elemen halaman.  
 Event Handling & Interaktivitas: Mengaitkan aksi pengguna (seperti klik tombol atau ketikan input) menggunakan ⁠addEventListener⁠ untuk menjalankan fungsi logika tertentu.  
 Validasi Form & Fitur Dinamis:
 Membuat fitur penghitung karakter langsung (live character counter).
 Memvalidasi input kosong dan format email menggunakan Regular Expression (⁠RegEx⁠).  
 Mencegah reload halaman saat submit menggunakan ⁠event.preventDefault()⁠.
